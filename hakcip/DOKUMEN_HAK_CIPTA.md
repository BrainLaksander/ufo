# Dokumen Induk Pendaftaran Hak Cipta

Dokumen ini merupakan panduan dan draf yang disiapkan untuk proses pendaftaran Hak Cipta (*Copyright*) Program Komputer **UFO (UNKLAB Forum Organization)** ke Direktorat Jenderal Kekayaan Intelektual (DJKI) Kementerian Hukum dan HAM Republik Indonesia.

## 1. Data Pendaftaran (Draft Form DJKI)
Saat Anda mendaftar melalui situs [e-hakcipta.dgip.go.id](https://e-hakcipta.dgip.go.id/), silakan gunakan data berikut sebagai acuan pengisian:

- **Jenis Permohonan**: Karya Umum
- **Jenis Ciptaan**: Program Komputer
- **Sub Jenis Ciptaan**: Program Komputer (Software/Aplikasi)
- **Judul Ciptaan**: Aplikasi Web Terintegrasi UFO (UNKLAB Forum Organization)
- **Uraian Singkat Ciptaan**: UFO adalah sebuah portal aplikasi web terintegrasi yang dirancang untuk mengelola kegiatan, kalender akademik ekstrakurikuler, dan alur perizinan (proposal & laporan) antara Mahasiswa, Unit Kegiatan Mahasiswa (UKM), dan bagian Kemahasiswaan di Universitas Klabat (UNKLAB).

## 2. Pemilik dan Pencipta Hak Cipta
- **Pencipta (Creator)**: [Isi dengan Nama Anda / Tim Developer yang melakukan coding]
  - *Catatan: Pencipta adalah orang yang secara fisik merancang dan menulis kode.*
- **Pemegang Hak Cipta (Copyright Holder)**: [Isi dengan Universitas Klabat atau entitas yang mendanai/menugaskan project ini]
  - *Catatan: Hak ekonomi (untuk komersialisasi/distribusi eksklusif) dimiliki oleh Pemegang Hak Cipta.*

## 3. Dokumen Lampiran (Checklist Persyaratan DJKI)
Pastikan Anda telah mengumpulkan seluruh berkas di bawah ini dalam bentuk `.pdf` dengan ukuran maksimal 5MB per dokumen:

- [ ] **1. Scan KTP Pemohon / Pencipta**
- [ ] **2. Surat Pernyataan Hak Cipta** (Dapat diunduh format resminya dari situs e-hakcipta, ditandatangani di atas meterai Rp10.000).
- [ ] **3. Surat Pengalihan Hak Cipta** (Wajib ADA apabila Pencipta berbeda dengan Pemegang Hak Cipta. Contoh: Programmer menyerahkan hak ke Universitas, tanda tangan kedua belah pihak di atas meterai).
- [ ] **4. Contoh Ciptaan / File Program**: 
  - Buat satu dokumen PDF yang berisi **Panduan Pengembangan Program** (dapat di-generate dari `PANDUAN_PENGEMBANGAN.md`).
  - Masukkan beberapa lembar *screenshot* halaman utama aplikasi (Halaman Mahasiswa, Kemahasiswaan, dan Pengurus UKM).
  - Copy-paste (salin) bagian *source code* inti dari aplikasi (contohnya isi file `KemahasiswaanController.php` atau `PengurusUkmController.php`) sebanyak 10 hingga 20 halaman ke dalam dokumen PDF tersebut sebagai bukti perwujudan ciptaan.
- [ ] **5. Scan NPWP Pemohon** (Opsional/Sesuai kebutuhan sistem).

## 4. Penting Terkait Open-Source & Framework
Aplikasi UFO dibangun menggunakan framework Laravel yang berlisensi **MIT License**. Hak cipta yang didaftarkan **TIDAK** mengklaim kepemilikan atas framework Laravel atau library JavaScript eksternal yang digunakan. 
Hak cipta ini secara eksklusif melindungi **struktur logika khusus (business logic), desain antarmuka, tata letak, dan modifikasi kode program** yang dibuat secara orisinal oleh Pencipta untuk kasus penggunaan Universitas Klabat.
