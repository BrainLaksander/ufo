# 🎨 UFO UI Design System - Dokumentasi

## 🎯 Overview

Dokumentasi lengkap UI Design System untuk project UFO dengan fokus pada:
- Konsistensi warna
- Responsivitas mobile-first
- Component reusability
- Modern aesthetic (kampus profesional)

---

## 🌈 Color Palette

### Primary Colors
```css
--primary: #663399        /* Ungu gelap - main accent */
--accent: #ffcc00         /* Kuning - highlight, buttons */
```

### Semantic Colors
```css
--danger: #cc0000         /* Red - errors, badges */
--success: #00aa00        /* Green - success states */
--warning: #ffa500        /* Orange - warnings */
```

### Neutral Colors
```css
--text-primary: #111      /* Dark text */
--text-secondary: #666    /* Medium gray text */
--bg-light: #f7f7fb       /* Light background */
--border-color: #e6e6f0   /* Light border */
```

### Shadows
```css
--shadow-sm: 0 2px 4px rgba(0, 0, 0, 0.06)
--shadow-md: 0 6px 12px rgba(0, 0, 0, 0.08)
--shadow-lg: 0 12px 24px rgba(0, 0, 0, 0.12)
```

### Color Usage
- **Ungu (#663399)**: Headers, primary buttons, active states, links
- **Kuning (#ffcc00)**: Sidebar, secondary buttons, icons, highlights
- **Merah (#cc0000)**: Badges, error messages, close buttons
- **Hijau (#00aa00)**: Success messages, checkmarks
- **Abu (#666)**: Descriptions, secondary text

24px  - 2XL

## 🎭 States & Interactions

### Button States
- **Default**: Gradient ungu, shadow-md
- **Hover**: Transform up 2px, shadow-lg, gradient darker
- **Active**: Transform 0px
- **Disabled**: Opacity 0.5

### Input States
- **Default**: Border #e6e6f0
- **Focus**: Border #663399, shadow rgba(102, 51, 153, 0.1)
- **Error**: Border #cc0000
- **Disabled**: Background #f0f0f0, opacity 0.5

### Card States
- **Default**: Shadow-md
- **Hover**: Shadow-lg, transform translateY(-4px)
- **Active**: Shadow-sm

### Chip States
- **Default**: Border #e6e6f0, background white
- **Hover**: Border #663399
- **Active**: Background #663399, color white, border #663399

## 📱 Responsive Breakpoints

### Mobile First Approach
```css
/* Mobile (default) */
/* < 640px */

/* Tablet */
@media (min-width: 640px) {
    /* 640px - 1024px */
}

/* Desktop */
@media (min-width: 1024px) {
    /* 1024px+ */
}
```

### Layout Grid
- **Mobile**: 1 column
- **Tablet**: 2 columns
- **Desktop**: 3+ columns

### Container Max Width
```css

```

### Padding Adjustments
| Breakpoint | Padding |
|-----------|---------|
| Mobile | 12px-16px |
| Tablet | 16px-20px |

## 🔧 Implementation Guide

### Using Color Variables
```css
/* ✅ DO */
background: var(--primary);
color: var(--text-secondary);
border: 1px solid var(--border-color);

/* ❌ DON'T */
background: #663399;
color: #666;
```

### Creating a New Component
1. Follow spacing system (multiples of 4px)
2. Use color variables
3. Add shadow: var(--shadow-md)
4. Add transitions: all 0.2s ease
5. Test on mobile, tablet, desktop
6. Add hover states
7. Add ARIA labels

### Mobile-First Development
1. Start with mobile layout
2. Stack elements vertically
3. Use single column
4. Add media queries for larger screens
5. Gradually enhance for desktop

## 🎨 Example: Building a New Card

```jsx
import React from 'react';

export default function MyCard({ title, content }) {
  return (
    <div className="my-card">
      <h3 className="my-card-title">{title}</h3>
      <p className="my-card-content">{content}</p>
      <button className="my-card-btn">Action</button>
    </div>
  );
}
```

```css
/* Using design system */
.my-card {
  background: white;
  border-radius: 12px;
  padding: 20px;
  box-shadow: var(--shadow-md);
  transition: all 0.2s ease;
}

.my-card:hover {
  transform: translateY(-4px);
  box-shadow: var(--shadow-lg);
}

.my-card-title {
  margin: 0 0 12px;
  font-size: 18px;
  font-weight: 700;
  color: var(--primary);
}

.my-card-content {
  margin: 0 0 16px;
  font-size: 14px;
  color: var(--text-secondary);
  line-height: 1.6;
}

.my-card-btn {
  padding: 12px 16px;
  background: linear-gradient(135deg, var(--primary) 0%, #5a2d7f 100%);
  color: white;
  border: none;
  border-radius: 8px;
  cursor: pointer;
  font-weight: 600;
  transition: all 0.2s;
}

.my-card-btn:hover {
  transform: translateY(-2px);
  box-shadow: 0 4px 12px rgba(102, 51, 153, 0.2);
}

/* Responsive */
@media (max-width: 640px) {
  .my-card {
    padding: 16px;
    border-radius: 10px;
  }

  .my-card-title {
    font-size: 16px;
  }
}
```

## 🚀 Performance Tips

1. **Minimize Repaints**: Use `transform` instead of `left`/`top`
2. **GPU Acceleration**: Use `transform` and `opacity` for animations
3. **Lazy Loading**: Load images and heavy content on demand
4. **CSS Optimization**: Minimize specificity, avoid `!important`
5. **Variable Reuse**: Define once, use everywhere
