## 🔌 Integration Examples

### Gunakan di Component Lain

```jsx
import StudentBurgerMenu from '../components/layout/StudentBurgerMenu';
import { useState } from 'react';

export default function MyPage() {
  const [menuOpen, setMenuOpen] = useState(false);
  
  return (
    <>
      <StudentBurgerMenu 
        open={menuOpen}
        onClose={() => setMenuOpen(false)}
        activeItem="organisasi"
      />
      <button onClick={() => setMenuOpen(true)}>
        Open Menu
      </button>
    </>
  );
}
```

### Gunakan Menu Config

```jsx
import { STUDENT_MENU_ITEMS, APP_INFO } from '../config/menuConfig';

// Iterate menu items
STUDENT_MENU_ITEMS.forEach(item => {
  console.log(item.label, item.icon, item.path);
});

// Access app info
console.log(APP_INFO.name, APP_INFO.version); // "UNKLAB Forum Organization", "1.0"
```

### Gunakan Hooks (Opsional)

```jsx
import { useKeyboardNavigation } from '../hooks/useMenuNavigation';

useKeyboardNavigation(menuOpen, handleClose); // Esc key support
```

## 🛠️ Customization Tips

### Ubah Menu Items
Edit `StudentBurgerMenu.jsx` atau gunakan `menuConfig.js`

### Ubah Warna
Edit `public/css/app.css` atau `menuConfig.js`:
```javascript
colors: {
  primary: "#YOURNEWCOLOR",
  accent: "#YOURNEWCOLOR",
}
```

### Ubah Animation Speed
Edit `public/css/app.css`:
```css
.student-burger-menu {
  transition: transform 0.3s ease; /* change 0.28s */
}
```

### Tambah Keyboard Support
Uncomment di `StudentBurgerMenu.jsx`:
```jsx
import { useKeyboardNavigation } from '../hooks/useMenuNavigation';
useKeyboardNavigation(open, onClose);
```

## ❓ FAQ

**Q: Gimana cara tambah menu item baru?**  
A: Edit `StudentBurgerMenu.jsx` di bagian `<ul>` atau update `menuConfig.js`

**Q: Warna tidak sesuai?**  
A: Check `app.css` class `.student-burger-menu` atau `menuConfig.js` colors

**Q: Menu tidak slide?**  
A: Check CSS file loaded, check z-index conflicts, check transform property

**Q: Esc key tidak work?**  
A: Uncomment `useKeyboardNavigation()` hook di component

**Q: Overlay tidak gelap?**  
A: Check `.student-menu-overlay` visibility dan z-index
